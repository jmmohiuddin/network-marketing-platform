## Contracts
- API client `lib/api.ts`: `useApi()` -> `{ request, get, post(path, body, opts), put, delete }` -> `ApiResult<T> { data, meta, status, headers }`; opts `{ query, idempotencyKey, headers (If-Match), signal, body }`. Sends X-Requested-With on POST/PUT/DELETE, JSON or FormData. Errors throw `ApiError { status, code, message, details, requestId }` (`isApiError(e, code?)`); NETWORK_ERROR (status 0), SERVICE_UNAVAILABLE (non-JSON). UNAUTHENTICATED -> `/signin?next=` (or `/signin/vendor` for /vendor targets), MFA_ENROLMENT_REQUIRED -> `/signin/enrol?next=`, MFA_VERIFICATION_REQUIRED -> `/signin/mfa?next=` via full navigation (`lib/leave-page.ts`), promise never settles. STEP_UP_REQUIRED -> StepUpDialog (ApiProvider) then one retry with the same Idempotency-Key; cancel throws STEP_UP_REQUIRED.
- Idempotency-Key: caller creates `crypto.randomUUID()` when the user starts the action, keeps it in state until success, passes `{ idempotencyKey }`.
- `lib/messages.ts`: `errorMessage(e)` (server message; client text for NETWORK/SERVICE/STEP_UP/NOT_FOUND/REALM_FORBIDDEN; 5xx -> "Something went wrong. Try again later. Reference: <id>"), `fieldErrors(e)` (VALIDATION_FAILED issues by path), `isNotAvailable(e)` (404/PERMISSION_DENIED/REALM_FORBIDDEN -> render `<NotAvailable/>`).
- Session: `useMe()` (GET /v1/me, reload), `useSession()` inside AppShell -> `{ me, can(permission) }`; `lib/me.ts` `Me`, `pendingMfaPath`, `homePath`, `shellRedirect`. Navigation = `me.navigation` from the API (paths /compliance, /imports, /settings/users, /settings/vendor-access, /settings/audit, /settings, /vendor). AppShell renders NotAvailable for paths outside the user's entries (UX guard; API enforces).
- `lib/navigation.ts`: `safeNext` (same-origin, not auth pages), `withNext`, `authRedirectPath`, `afterSignInPath`, `activeEntry`, `signedOutPath`, `realmOf`, `defaultHome`.
- Components: Button/LinkButton (variant primary|secondary|tertiary|destructive|destructive-solid, size md|lg, loading), FormField (render prop), TextField, SelectField (options, placeholder), Checkbox (indeterminate), FileInput (extensions, maxBytes, onFiles), ErrorSummary (items {fieldId?, message} held in state), Banner (tone, title, action), StatusChip (state, label; `toneOf`), Table (caption, columns {key, header, cell, align, sortable}, rows, rowKey, loading, error {message,onRetry}, empty {title, action}, sort/onSortChange, pagination {hasPrevious, hasNext, onPrevious, onNext}, density) + `useCursorPages()`, Dialog (open, onClose, title, size, footer; `data-autofocus`), ConfirmDialog (title, consequence, confirmLabel, destructive, onConfirm async, onCancel), ToastProvider/`useToast()({message, tone})`, PageHeader (title, state, summary, actions), Tabs/TabPanel (label, idPrefix, tabs, selected, onSelect), SecretText (label, value), QrCode (value, label, size), CodeForm (idPrefix, endpoint, submitLabel, onVerified, secondaryAction), SignOutButton (realm), ThemeSelect, EmptyState/LoadingState/ErrorState/NotAvailable, AppShell (realm).
