Market currency frozen once a ledger account or batch exists.
- **Lock order:** run lock → `periods:` lock → market ledger lock → tenant audit lock. A CAS `onDecision` runs after the decision's audit, so it only TRIES locks (409 LEDGER_BUSY, 409 PERIOD_NOT_OPEN `{state: busy}`).
- **Payouts:** one instruction per batch line (same payee, amount, current bank version); retries set `retry_of`; a batch settles when every instruction not replaced by a retry is settled; recalculation returns the batch to draft. Pending instruction row = outbox record; status query before any resend. Adapters `sandbox`, `bank_file_csv` only. Webhook `POST /v1/webhooks/providers/:providerConfigId`, HMAC over `<X-Sandbox-Event-Id>.<X-Sandbox-Timestamp>.<raw body>`, ±300 s; amounts as decimal strings. Result files: bank_file_csv only, importer ≠ preparer/submitter/file generator.
- **Cases:** `approvals_required` pinned at submit (1 | 2); list shows null for open cases; second approver ≠ first; related staff excluded (adjustment, write_off, batch approve/retry). Write-off create outside scope = 422 SUBJECT_NOT_FOUND (C-B4-24).
