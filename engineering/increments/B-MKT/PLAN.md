| D-BM-03 | **Withholding rule model (BR-TAX-01/03).** A `tax_rule` row of kind `withholding`: `conditions` = `{entity_types?: [individual\|company\|partnership\|other], residency?: [ISO-3166 alpha-2]}` (a payee matches when every present list contains the value of its tax profile in force at the pay instant; an absent profile or NULL value matches only a rule without that condition); `rate` NULL = **"no withholding duty in this market"** (applied as rate 0, basis `no_duty`, no review flag) else 0 ≤ rate ≤ 1 with `rounding ∈ {half_up, half_even}` (the engine's modes); `threshold_minor` and `threshold_basis` both or neither, basis ∈ `prior_year_payer_total` (the payee's gross from this payer in this market in the previous tax year must exceed the threshold, else nothing is withheld this year) or `current_year_cumulative` (withhold from the run in which the payee's gross from this payer in the current tax year, including this run, first exceeds the threshold, and in every later run of that year; **no catch-up** of earlier amounts, §8 O-6); `missing_id_rate` (only with `rate`) applies when the payee has no tax id at the pay instant (BR-TAX-03). **Pay instant** of a run = the period's end (last µs), **tax date** = that instant's date in the market zone (C-BM-12); the rules in force on the tax date are used; the tax profile in force at the pay instant decides conditions and tax id (a tax id given later applies from the next period, never retroactively: US-19 alt). **Tax year** from the pack's `tax_year` rule (`start_month`, `start_day`; label = calendar year in which it starts). Selection per payee: the withholding rules of the market's pack in force on the tax date whose conditions match; **none** → no instruction (engine warns `NO_WITHHOLDING_RULE`: zero withholding, review exception — FR-TAX-002 err); **more than one** → the run is refused 422 TAX_RULES_INVALID `{code: 'TAX_RULE_AMBIGUOUS', rule_ids, participant_ids (≤ 20)}` (pack data error); a threshold basis with no `tax_year` rule → 422 TAX_RULES_INVALID `{code: 'TAX_YEAR_NOT_DEFINED'}`. Gross for thresholds = `run_settlement.gross_minor` of the market's **committed** runs (run state `committed`; periods committed/paid/closed) whose tax date falls in the year. **Known limit (decided, §8):** payments made before the tenant's first committed run on the platform (first platform year, or a mid-year B6 cutover) are **not counted** — under `prior_year_payer_total` nothing is withheld in the first platform tax year, and `current_year_cumulative` counts from go-live/cutover only; SC-12 Withholding rules states it for every threshold rule.
